# 🎯 Smart Attendance System (Face Recognition)

An intelligent attendance system that uses **face recognition** to automatically mark attendance in real-time.

---

## 📌 Overview

This project detects faces using a webcam and matches them with stored images to mark attendance automatically.

💡 No manual work  
💡 Fast and accurate  
💡 Beginner-friendly project  

---

## ✨ Features

- Face Detection & Recognition  
- Automatic Attendance Marking  
- Stores data in CSV file  
- Optimized for low RAM usage  
- Simple and clean code  

---

## 🧠 How It Works

1. Load dataset of face images  
2. Encode facial features  
3. Start webcam  
4. Detect and recognize face  
5. Mark attendance in CSV file
